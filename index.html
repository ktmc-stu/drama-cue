Drama Cue

A sound cue desk for theatre. Standby, GO, fade, and stop from one keyboard.

  • Audio, fade, stop, wait and memo cues
  • Per-cue level, pan, trim and live fades
  • Firebase sync with offline fallback
  • Password locked for internal use

Internal use only. Sound plays only when you press GO.

Accounts are created in Firebase by the administrator.

Firebase setup

  1. Create a Firebase project and add a Web app.
  2. Paste the config into firebase-config.js.
  3. Enable Email/Password sign-in and disable sign-up.
  4. Add a crew user in Authentication.
  5. Create Firestore and Storage, then apply the rules files.
  6. Add your GitHub Pages domain to Authorized domains.
